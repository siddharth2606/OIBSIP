# Car Price Prediction with Machine Learning

## Objective
Build a regression model to predict the selling price of used cars based on features such as brand, age, mileage, fuel type, and transmission.

## Dataset
Vehicle dataset from CarDekho.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed
1. Data Loading
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis
5. Categorical Encoding
6. Correlation Analysis
7. Train-Test Split
8. Model Training
9. Model Evaluation
10. Feature Importance

## Feature Engineering
- Calculated car age from the year.
- Extracted car brand from the car name.

## Models Used
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- MAE
- RMSE
- R² Score

## Result
The models were compared using MAE, RMSE and R² score, and the best-performing model was selected based on the evaluation results.

`Car_Price_Prediction.ipynb`
