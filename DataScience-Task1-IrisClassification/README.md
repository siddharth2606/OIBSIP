# Iris Flower Classification

## Objective
Predict the species of an Iris flower using its physical measurements.

## Dataset
Iris dataset from scikit-learn.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Steps Performed
1. Data Loading
2. Exploratory Data Analysis
3. Data Visualization
4. Feature Analysis
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Comparison

## Models Used
- Logistic Regression
- K-Nearest Neighbours

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Result
The linear Regression model (Accuracy 100%) was selected based on the evaluation results.

## Project File
`Iris_Classification.ipynb`
